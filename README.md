# ReBorn — MVP 2.1

Минималистичное PWA-приложение для личной дисциплины.

## Возможности
- Чёрно-белый интерфейс и короткая заставка ReBorn.
- Ежедневный список действий со статусами: выполнено (зелёная галочка), пропущено (красный крестик).
- Гибкое расписание: время — ориентир; действия можно переносить и менять длительность.
- Редактирование действий: название, эмодзи-иконка, раздел, время начала, длительность и повторение по дням недели.
- Создание собственных разделов и рабочих блоков на 25/45/60 минут, а также перерывов.
- Вечерний отчёт, история, простая статистика.
- Экспорт и импорт резервной копии JSON.
- PWA-режим и офлайн-оболочка.

## Публикация
Загрузите файлы в корень GitHub-репозитория и включите GitHub Pages (ветка `main`, папка `/(root)`). Затем откройте выданную HTTPS-ссылку в Safari на iPhone и выберите «Поделиться» → «На экран Домой».

## Данные и ограничения
Отметки и настройки хранятся локально в браузере на конкретном устройстве. Облачной синхронизации и push-уведомлений пока нет. Периодически скачивайте резервную копию JSON.
